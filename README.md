# 🥐 Baked Bounty

Static bakery website frontend built as a small business storefront demo.

🔗 **Live Demo:** https://bakedbounty.netlify.app

---

## 📌 Overview

**Baked Bounty** is a multi-page static website designed for a local bakery business.  
The project focuses on layout, responsiveness, and visual presentation rather than backend functionality.

It was initially built as a commissioned request and is now maintained as a portfolio and practice project.

---

## ✨ Features

- Multi-page website structure (Home, About, Shop, etc.)
- Responsive design for desktop and mobile devices
- Static product listings
- Clean UI suitable for food and small retail businesses
- Deployed using Netlify

## 🚀 Installation

This is a static website. No build tools or dependencies are required.

```bash
git clone https://github.com/BVKSH0/Baked-Bounty.git
cd Baked-Bounty
```

Open index.html in a browser or serve it using any static file server.

---

## 📂 Usage

- Intended as a frontend demo or template

- Content can be customized by editing the HTML and CSS files directly

- Suitable for showcasing UI design and frontend fundamentals

---

## ⚠️ Limitations

- This project does not include:

- Backend or server-side logic

- Database or persistent storage

- Shopping cart or checkout system

- Payment processing

- Admin dashboard or CMS

- User authentication

- All products and content are statically defined.
